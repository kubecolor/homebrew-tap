# homebrew-tap
Homebrew tap to install Kubecolor

> [!WARNING]
> This tap has been deprecated for a while. Please refer to [the `kubecolor` homebrew formulae](https://formulae.brew.sh/formula/kubecolor) instead.
>
> If you previously installed kubecolor using this homebrew tap, then uninstall it before reinstalling kubecolor via the formulae:
>
> ```bash
> brew uninstall kubecolor
> brew untap kubecolor/tap
> brew update
> brew install kubecolor
> ```
